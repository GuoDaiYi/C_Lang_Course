# C 语言速查表

新手不需要背语法，写代码的时候把这份表放在旁边查就行。

**怎么用这份表**：卡住了先看最后一节「我想做 X → 用什么」定位到知识点，
再回到对应小节看写法。每一课的文件头里也有「本节课新出现的语法」清单，
只查那一课新学的东西会更快。

## 程序骨架

```c
#include <stdio.h>      /* 用到 printf / scanf 就要写这行 */

int main(void) {        /* 程序入口，必须有，而且只能有一个 */
    printf("hi\n");
    return 0;           /* 返回 0 表示正常结束 */
}
```

## 常用头文件

| 头文件 | 提供什么 | 什么时候要写 |
| --- | --- | --- |
| `<stdio.h>` | `printf` `scanf` `fopen` `fgets` | 几乎每节课都要 |
| `<string.h>` | `strlen` `strcpy` `strcat` `strcmp` | 处理字符串时 |
| `<math.h>` | `sqrt` `pow` `fabs` `sin` | 用到数学函数时（编译加 `-lm`） |
| `<stdlib.h>` | `rand` `srand` `malloc` `free` `exit` | 随机数、动态内存 |
| `<time.h>` | `time` `clock` | 计时、随机数种子 |
| `<ctype.h>` | `isdigit` `isalpha` `toupper` | 判断字符属于哪一类 |
| `<stdbool.h>` | `bool` `true` `false` | 想用 `true/false` 时 |
| `<stddef.h>` | `NULL` `size_t` | 想显式写 `NULL` 时 |

> 头文件写错了会报 `file not found`；用了函数却忘了写对应头文件，
> 会报 `implicit declaration of function 'xxx'`。

## 数据类型与格式符

| 类型 | 说明 | 例子 | `printf` 格式符 | `scanf` 格式符 |
| --- | --- | --- | --- | --- |
| `int` | 整数 | `int n = 42;` | `%d` | `%d` |
| `long long` | 更大的整数 | `long long big = 9000000000LL;` | `%lld` | `%lld` |
| `float` | 小数（精度低） | `float f = 1.5f;` | `%f` | `%f` |
| `double` | 小数（默认用这个） | `double d = 3.14;` | `%f` | `%lf` |
| `char` | 单个字符 | `char c = 'A';` | `%c` | `%c` |
| `char[]` | 字符串（字符数组） | `char s[20] = "你好";` | `%s` | `%s` |
| `int[]` / `double[]` | 数组 | `int a[5];` | 需要循环打印 | — |

> `float` 用 `scanf` 是 `%f`，`double` 用 `scanf` 是 `%lf`——**这里多个 l，新手最容易记错**。

### printf 格式符完整对照

| 写法 | 含义 | 例子 | 输出 |
| --- | --- | --- | --- |
| `%d` | 整数 | `printf("%d", 42)` | `42` |
| `%f` | 小数 | `printf("%f", 3.14159)` | `3.141590` |
| `%.2f` | 保留 2 位小数 | `printf("%.2f", 3.14159)` | `3.14` |
| `%8.2f` | 总宽度 8、右对齐 | `printf("%8.2f", 3.14)` | `    3.14` |
| `%-8.2f` | 总宽度 8、左对齐 | `printf("%-8.2f", 3.14)` | `3.14    ` |
| `%c` | 单个字符 | `printf("%c", 'A')` | `A` |
| `%s` | 字符串 | `printf("%s", "hi")` | `hi` |
| `%p` | 指针地址 | `printf("%p", (void *)&n)` | `0x7ffd...` |
| `%zu` | `sizeof` 的结果 | `printf("%zu", sizeof(int))` | `4` |
| `%ld` | `long` | `printf("%ld", 10L)` | `10` |
| `%%` | 百分号本身 | `printf("100%%")` | `100%` |

> 宽度和精度可以组合：`%-10.2f` = 左对齐 + 总宽 10 + 2 位小数。
> 宽度不够时不会截断，只会撑开，所以别指望 `%5d` 能把长的数字切掉。

## 运算符

```c
a + b    a - b    a * b    a / b    /*加减乘除*/
a % b   /* % 取余，只能用于整数 */

a++      /* 自增 1：a = a + 1 */
a--      /* 自减 1 */
a += 5   /* 等价于 a = a + 5，同理 -= *= /= */

a == b   /* 判断相等（注意是两个等号！） */
a != b   /* 不等于 */
a < b    a > b    a <= b    a >= b

a && b   /* 并且：两边都真才真 */
a || b   /* 或者：只要一边真就真 */
!a       /* 取反 */
```

### 运算符优先级（从高到低）

```
1.  ( )  []  ->  .          括号、数组下标、取成员
2.  !  ~  ++  --  (前缀)    一元运算符
3.  *  /  %                 乘、除、取余
4.  +  -                    加、减
5.  <  >  <=  >=            比较
6.  ==  !=                  相等判断
7.  &&                      并且
8.  ||                      或者
9.  =  +=  -=  *=  /=  %=   赋值
```

> 记不住没关系：**能用括号就加括号**，`(a + b) * c` 比 `a + b * c` 清楚得多，
> 而且绝不会算错。`a + b * c` 实际是 `a + (b * c)`。
>
> 常见陷阱：`count++` 和 `++count` 在单独一行时没区别，
> 但写成 `printf("%d %d", i++, i)` 就会出现「不确定」的结果——别这么写。

## 条件与循环

```c
if (score >= 60) {
    printf("及格\n");
} else if (score >= 50) {
    printf("补考\n");
} else {
    printf("不及格\n");
}

for (int i = 0; i < 5; i++) {   /* 最常用：知道要循环几次 */
    printf("%d\n", i);
}

while (条件) { ... }             /* 条件为真就一直转 */
do { ... } while (条件);          /* 至少执行一次 */

break;      /* 立刻跳出整个循环 */
continue;   /* 跳过本次，进入下一次 */
```

## switch / case（多分支选择）

```c
switch (choice) {
    case 1:
        printf("一\n");
        break;                  /* break 不能忘 */
    case 2:
    case 3:                     /* 多个 case 共用一段代码 */
        printf("二或三\n");
        break;
    default:                    /* 都不匹配时走这里 */
        printf("其他\n");
}
```

| 写法 | 说明 |
| --- | --- |
| `switch (表达式)` | 表达式必须是**整数类型**（`int`、`char`），不能是 `double` 或字符串 |
| `case 常量:` | 常量必须能写死在编译期，不能是变量；同一个 switch 里不能重复 |
| `break;` | 跳出 switch。**漏写会「贯穿执行」**，继续往下跑下一个 case |
| `default:` | 兜底分支，建议一定写；可以放在 switch 的任意位置 |

```c
/* 字符也能用 switch，常见于菜单和按键处理 */
switch (key) {
    case 'A':
    case 'a':   printf("新增\n"); break;
    case 'q':   printf("退出\n"); break;
    default:    printf("未知按键\n");
}
```

| 场景 | 用哪个 |
| --- | --- |
| 判断「等于某个具体值」（菜单、选项、运算符） | `switch` |
| 判断范围（`>= 60`）或组合条件（`&&`、`\|\|`） | `if` |

## 数组与字符串

```c
int scores[5] = {90, 85, 77, 60, 100};
scores[0] = 95;                  /* 下标从 0 开始，第 1 个是 [0] */
int n = sizeof(scores) / sizeof(scores[0]);   /* 元素个数 */

int grid[3][4];                  /* 二维数组：3 行 4 列 */
grid[1][2] = 7;

char name[20] = "Lucy";          /* 字符串就是字符数组，末尾有隐藏的 '\0' */
```

`string.h` 里常用的函数：

| 函数 | 作用 | 注意 |
| --- | --- | --- |
| `strlen(s)` | 字符串长度（不含 `\0`） | — |
| `strcpy(dst, src)` | 复制字符串 | `dst` 要够大 |
| `strcat(dst, src)` | 拼接字符串 | `dst` 要够大 |
| `strcmp(a, b)` | 比较：相等返回 `0` | 不能用 `==` 比较字符串 |

## 指针

```c
int n = 10;
int *p = &n;          /* & 取地址：p 保存 n 的地址 */
printf("%d\n", *p);   /* * 解引用：取出地址里的值，输出 10 */
*p = 20;              /* 通过指针修改 n，此时 n 变成 20 */

int *empty = NULL;    /* 空指针：先判断 if (p != NULL) 再用 */
```

一句话理解：**指针就是存地址的变量**，`&` 拿来地址，`*` 拿去内容。

## 函数

```c
int add(int a, int b);        /* 声明（原型），写在 main 前面 */

int main(void) {
    printf("%d\n", add(3, 4));
    return 0;
}

int add(int a, int b) {       /* 定义，写在后面 */
    return a + b;
}
```

C 的参数是**值传递**：函数里改参数，不会影响外面的变量（要改就得传指针）。

## 结构体

```c
typedef struct {
    char name[20];
    int  score;
} Student;

Student s = {"Lucy", 95};
printf("%s %d\n", s.name, s.score);   /* 用点访问成员 */

Student *p = &s;
printf("%s\n", p->name);              /* 用箭头访问成员 */
```

## 文件读写

```c
FILE *fp = fopen("data.txt", "w");    /* "r" 读 "w" 覆盖写 "a" 追加 */
if (fp == NULL) {                     /* 打开失败一定要判断 */
    printf("打不开文件\n");
    return 1;
}
fprintf(fp, "%d %s\n", 1, "Lucy");
fclose(fp);                           /* 用完必须关 */

/* 按行读取 */
char line[100];
FILE *in = fopen("data.txt", "r");
while (fgets(line, sizeof(line), in) != NULL) {
    printf("%s", line);
}
fclose(in);
```

## 数学函数（math.h）

```c
#include <math.h>      /* Linux 上编译还要加 -lm */
```

**所有数学函数的参数和返回值都是 `double`。**

| 函数 | 作用 | 例子 |
| --- | --- | --- |
| `sqrt(x)` | 平方根 | `sqrt(2.0)` → 1.414214 |
| `pow(x, y)` | x 的 y 次方 | `pow(2.0, 10.0)` → 1024 |
| `fabs(x)` | 绝对值 | `fabs(-3.7)` → 3.7 |
| `exp(x)` | e 的 x 次方（e ≈ 2.71828） | `exp(1.0)` → 2.718282 |
| `log(x)` | 自然对数（底数 e） | `log(10.0)` → 2.302585 |
| `log10(x)` | 常用对数（底数 10） | `log10(100.0)` → 2 |
| `log2(x)` | 二进制对数（底数 2） | `log2(8.0)` → 3 |

### 三角函数

| 函数 | 作用 | 注意 |
| --- | --- | --- |
| `sin(x)` `cos(x)` `tan(x)` | 正弦、余弦、正切 | **参数是弧度，不是角度** |
| `asin(x)` `acos(x)` `atan(x)` | 反三角函数 | 返回的也是弧度；`asin`/`acos` 的输入要在 -1~1 |
| `atan2(y, x)` | 带象限的反正切 | 需要方向、象限时用它，别用 `atan(y/x)` |
| `hypot(x, y)` | 勾股定理求斜边 | 比 `sqrt(x*x+y*y)` 更稳，不会溢出 |

```c
弧度 = 角度 * M_PI / 180.0;
角度 = 弧度 * 180.0 / M_PI;

sin(30.0 * M_PI / 180.0)   /* = 0.5，才是 30 度 */
```

### 取整与取余

| 函数 | 作用 | 例子 |
| --- | --- | --- |
| `floor(x)` | 向下取整（往小的） | `floor(-3.2)` → -4 |
| `ceil(x)` | 向上取整（往大的） | `ceil(-3.2)` → -3 |
| `round(x)` | 四舍五入，`.5` 远离 0 | `round(2.5)` → 3，`round(-2.5)` → -3 |
| `trunc(x)` | 截断小数（朝 0） | `trunc(-3.2)` → -3 |
| `fmod(x, y)` | 小数取余（整数用 `%`） | `fmod(7.5, 2.0)` → 1.5 |

### 特殊值检查

| 函数 | 作用 |
| --- | --- |
| `isnan(x)` | 是不是 NaN（算不出来的数，比如 `sqrt(-1.0)`） |
| `isinf(x)` | 是不是无穷大（比如 `1.0 / 0.0`） |

> `M_PI` 不是标准 C，各平台不一定给，自己定义最保险：
> `#define M_PI 3.14159265358979323846`

### math.h 三个最容易踩的坑

1. Linux 上编译要加 `-lm`，否则链接报 `_sqrt` 找不到。
2. `(int) 3.9` 是**截断**不是四舍五入，要四舍五入请用 `round`。
3. 保留两位小数的值本身（不是只格式化打印）：`round(x * 100.0) / 100.0`。

## 编译命令

```bash
cc hello.c -o hello                  # 最基础
cc -Wall -Wextra -std=c11 a.c -o a   # 打开警告（养成习惯）
cc -Wall -Wextra -std=c11 a.c -o a -lm   # 用了 math.h 就加 -lm
cc -g a.c -o a                       # 带调试信息，配合 gdb/lldb
./a                                  # 运行
./a < input.txt                      # 从文件喂输入
./a > out.txt                        # 把输出存到文件
```

## 新手十大坑（对照着检查一遍）

1. **忘了分号** —— 每条语句结尾都要 `;`。
2. **忘了 `&`** —— `scanf("%d", &n)`，少一个 `&` 就会读到随机地址，可能直接崩。
3. **`scanf` 读 `double` 用 `%lf`**，但 `printf` 打印 `double` 还是 `%f`。
4. **整数除法丢小数** —— `5 / 2` 是 `2`，要写 `5.0 / 2` 或 `(double)5 / 2`。
5. **`=` 和 `==` 搞混** —— `=` 是赋值，`==` 才是比较。
6. **`switch` 里漏 `break`** —— 会「贯穿执行」，选了 1 却把 2 的内容也打印了。
7. **数组下标越界** —— 长度 5 的数组只有 `[0]`~`[4]`，`[5]` 就越界了。
8. **字符串忘了结尾的 `'\0'`** —— `char s[3] = "abc"` 会越界，要留 4 个位置。
9. **解引用空指针** —— 用指针前先 `if (p != NULL)`。
10. **用了 `math.h` 却没加 `-lm`** —— Linux 上链接会报 `_sqrt` 找不到。
